# Aptitude Quiz App – iOS

A basic-to-intermediate SwiftUI iOS project suitable for an academic project and GitHub.

## Features
- 10 aptitude questions
- Multiple-choice answers
- Score calculation
- Progress indicator
- Next/Previous navigation
- Final result screen
- Restart quiz option
- Simple SwiftUI interface

## Requirements
- macOS
- Xcode
- iOS 17.0 or later

## Run
1. Open `AptitudeQuizApp.xcodeproj` in Xcode.
2. Select an iPhone Simulator.
3. Press **Run (▶)**.
